- New document: File > New, or Ctrl+N. Save with Ctrl+S (Save As: F12).
- Headings and styles: Home tab > Styles; apply Heading 1/2 for structure.
- Bulleted or numbered list: Home tab > Bullets / Numbering.
- Insert a table: Insert tab > Table.
- Page layout (margins, orientation): Layout tab.
- Spell check and editor: Review tab > Editor (or F7).
- Export to PDF: File > Export > Create PDF/XPS, or Save As with PDF type.
