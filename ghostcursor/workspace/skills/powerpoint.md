- New presentation: File > New, or Ctrl+N. Save with Ctrl+S.
- Add a slide: Home tab > New Slide, or Ctrl+M.
- Apply a theme (including dark ones like Ion or Integral): Design tab > Themes.
- Insert a chart: Insert tab > Chart; a datasheet opens for the numbers.
- Change layout: Home tab > Layout.
- Prefer charts over tables when the user asked for charts.
