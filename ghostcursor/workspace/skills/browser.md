- New tab: Ctrl+T. Close tab: Ctrl+W. Reopen closed tab: Ctrl+Shift+T.
- Go to an address: click the address bar (or Ctrl+L) and type the URL, Enter.
- Find on page: Ctrl+F. Back: Alt+Left.
- Prefer the page's own visible buttons and links over keyboard shortcuts.
