- New tab: Ctrl+T. Close tab: Ctrl+W. Reopen the last closed tab: Ctrl+Shift+T.
- Go to an address: Ctrl+L focuses the address bar, type the URL, press Enter.
- Find on the page: Ctrl+F. Reload: Ctrl+R or F5.
- Bookmark the current page: Ctrl+D.
- Back / forward: Alt+Left / Alt+Right.
- Downloads: Ctrl+J. History: Ctrl+H.
- Work on the control that is actually on the page; do not assume a link is
  present until it is observed.
