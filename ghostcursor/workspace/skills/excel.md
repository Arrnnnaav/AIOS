---
triggers: excel, xlsx, spreadsheet, workbook, cell, formula, pivot, chart
---
- New workbook: File > New, or Ctrl+N. Save with Ctrl+S.
- Enter data: click a cell, type, press Enter (down) or Tab (right).
- A formula starts with "=": e.g. =SUM(A1:A10), =AVERAGE(B2:B20).
- Format cells (number, currency, date): Home tab > Number, or Ctrl+1.
- Insert a table: select the range, Insert tab > Table (Ctrl+T).
- PivotTable: Insert tab > PivotTable.
- Chart: select the range, Insert tab > Chart; prefer a chart over a table when
  the user asked for a chart.
- Freeze headers: View tab > Freeze Panes.
