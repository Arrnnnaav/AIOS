- New workbook: File > New, or Ctrl+N. Save with Ctrl+S.
- Enter data: click a cell, type, press Enter or Tab.
- Insert a chart: select the range, then Insert tab > Charts.
- Insert a PivotTable: Insert tab > PivotTable.
- A formula starts with "=", e.g. =SUM(B2:B10). Confirm with Enter.
- Apply a theme: Page Layout tab > Themes.
