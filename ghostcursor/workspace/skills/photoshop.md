triggers: photoshop, psd, layer, layers, mask, brush, export as, image edit
---
- Work through Photoshop's menus, panels, tool buttons and dialogs -- these are
  real, observable controls. Orbyn points at and acts on observed controls only;
  it does NOT paint on the canvas or drag at a guessed position.
- Open / new: File > Open (Ctrl+O), File > New (Ctrl+N). Save: Ctrl+S.
- Pick a tool from the Tools panel by its button (Move, Brush, Marquee, etc.);
  tool options appear in the options bar at the top.
- Layers panel: New Layer, delete, group, toggle visibility (the eye). Add a
  mask with the "Add layer mask" button at the panel's bottom.
- Adjustments: Image > Adjustments (Levels Ctrl+L, Curves Ctrl+M, Hue/Sat
  Ctrl+U), or the Adjustments panel for non-destructive adjustment layers.
- Image size / canvas: Image > Image Size (Ctrl+Alt+I), Image > Canvas Size.
- Export: File > Export > Export As (Ctrl+Alt+Shift+W) or Save a Copy; choose
  the format in the dialog.
- Freehand painting, exact brush strokes and canvas coordinates are not
  something Orbyn performs -- it drives the UI around them, with your approval.
