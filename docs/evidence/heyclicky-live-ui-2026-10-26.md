# HeyClicky 1.1.1 and Orbyn workspace: live UI comparison

26 October 2026. The installed HeyClicky app was already running. I opened its windows and observed the desktop board, an expanded result, and the Account, Integrations, Agents and Routines settings pages. I did not start a HeyClicky agent, connect an app, change a setting, or create a routine. Local screenshots include private desktop content and remain untracked under `.tmp/`; the expanded result is retained locally as `.tmp/heyclicky-card-invoke.png` after invoking the board's accessible result button. This record contains only the observations needed for the product comparison. Orbyn was viewed at a 500 px browser viewport using a seeded local workspace server; that is a UI check, not a live model or Teach acceptance run.

The useful interaction pattern is **a work card that leads directly to its live state or result**. Orbyn's Work board adopts that pattern only where it has a real destination. It deliberately keeps the docked workspace, the observed-control Teach overlay and the existing Act authority path. This slice changes `ghostcursor/workspace/app.html` only; no new input, connector, scheduler or persistence path was added.

UI checks: `node --check` passed for the extracted page script. A seeded Playwright run at 500 px opened Work, changed cards by button and keyboard, confirmed model-supplied markup appeared as literal text, opened the Plan tab from its card, and confirmed the running card called `/api/stop`. The first keyboard check exposed a disabled-button focus gap; making the board a focusable named region fixed it, and the same check passed. Review then found that a changed status poll could remove focus and repeat a live announcement. A follow-up seeded run changed the state during focus on the Next control and on the region: focus survived both refreshes, navigation still announced the selected card, and an unchanged card was not re-announced on poll. The page console reported no errors. The screenshots were inspected locally and were not committed.
